#chem_bot
Химический бот

Данный бот позволяет:
1) Находить структуру SMILES молекулы по одному из параметров на выбор:
   - по названию;
   - по ID;
2) Искать похожие молекулы (сходство не менее 70%) по названию и по структуре SMILES;
3) Рассчитывать физико-химические дескрипторы для последней найденной молекулы.

Разработано для: НИЛ "Интеллектуальная химическая робототехника" (КФУ, Химический институт им. А.М. Бутлерова)
Автор: Голубь А.О.
